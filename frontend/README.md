# ImportFlow — Frontend

Interface React (Vite + TypeScript) do wizard de importação de produtos.

Documentação completa do projeto: [README na raiz](../README.md).

## Desenvolvimento

```bash
npm install
npm run dev
```

- App: `http://localhost:5173`
- Proxy `/api` → backend em `http://localhost:3001`

Build de produção: `npm run build` (saída em `dist/`).
